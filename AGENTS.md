# AGENTS.md

Instructions for AI agents using or developing PERSEO.

## Using PERSEO for an analysis

Read `inst/skills/perseo/SKILL.md` first. If the package is installed, the same folder is at
`system.file("skills/perseo", package = "PERSEO")`. It contains:

- the input contract and output schema
- verified pitfalls
- a CLI runner (`scripts/perseo_run.R`) that validates inputs, fits the models and prints a
  compact summary

Load `references/*.md` only when needed. Prefer the skill over the README examples.

## Developing PERSEO

- Sources are in `R/` and tests in `tests/testthat/`. Run the tests with `devtools::test()`.
- Always test against the current working copy (`devtools::load_all()` or `R CMD INSTALL .`),
  never an older installed PERSEO.
- `NAMESPACE` and `man/` are generated by roxygen2. Edit the roxygen comments and run
  `devtools::document()`.
- dplyr's `%>%` is imported for internal use (`@importFrom dplyr %>%`); it is not re-exported.
- Family names must exist in `gamlss.dist`, because unknown names are skipped silently.
  `default_candidate_families()` and `family_groups()` must only list real families.
- If you change exported signatures, output columns, family sets or defaults, update
  `inst/skills/perseo/` in the same change and add an entry to `CHANGELOG.md`.
- `datasets/counts_brca.rds` has 60k genes x 1231 samples, and a full run takes hours. For
  checks, use small synthetic data or the runner's `--check` / `--subset` options.
